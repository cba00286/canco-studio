# P02 빛은 부술 때만 쓰는 게 아니야 — 제작 작업지

`5컷 · 캐릭터 등장 5컷 · 배경만 0컷`

## 만드는 순서

1. **① 이미지 프롬프트**로 키프레임을 뽑는다 (Nano Banana 2)
2. 그 이미지를 **Image to Video** 에 넣고 **② 영상 프롬프트**를 붙인다 (MiniMax H3)
3. 파일명을 컷 ID 로 맞춘다 — `P02-01.png` / `P02-01.mp4`
4. 다 모이면 로컬에서 이어붙이기 · 자막 · 소리 믹싱

> **대사와 효과음은 ② 영상 프롬프트가 만든다.** 나레이션 · BGM · 자막은 로컬에서 얹는다. 이 구분을 헷갈리면 다시 만들어야 한다.

## 생성 설정 — 컷마다 같다

| | |

| 비율 | **9:16 세로** |
| 네거티브 | 아래 한 줄을 매번 같이 넣는다 |

```
text, watermark, signature, copyright, blurry, low resolution, deformed, extra limbs, scary, photorealistic human, off-model character, redesigned character, changed face, different proportions, inconsistent character design, different outfit, enlarged horns, oversized horns, elongated horns, long horns, thick horns, prominent horns, adult triceratops horns, growing horns, extra horns
```

> **비율은 프롬프트가 아니라 생성 화면의 설정이다.** 프롬프트에 «16:9» 라고 적어도 설정이 1:1 이면 1:1 로 나온다.

> **캐릭터 지정을 빼먹지 않는다.** 프롬프트에 이름만 적고 OpenArt 에서 캐릭터를 고르지 않으면, 이름은 그냥 글자일 뿐이라 얼굴이 매번 달라진다.

## 막힐 때

- **얼굴이 매번 달라진다** — 캐릭터 지정을 빼먹었다. 프롬프트의 이름만으로는 안 된다
- **대사를 안 한다** — 영상 프롬프트를 영어로 바꿨다. 통째로 한국어여야 한다
- **컷 톤이 다르다** — 프롬프트를 손으로 고쳤다. 마음에 안 들면 **시드를 바꿔** 다시 뽑는다
- **소품이 중간에 생긴다** — 영상 프롬프트의 `[외형]` 줄을 지웠다
- **클립에 엉뚱한 음악이 깔린다** — `[소리]` 줄의 «배경음악 없이» 를 지웠다
