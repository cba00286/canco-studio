# 16. 쇼츠

## 본편 컷을 잘라 쓸 수 없다

가장 먼저 알아야 할 것. 본편 600컷은 프롬프트에 `16:9 cinematic composition` 이
박혀 있고, 그 비율에 맞춰 인물과 여백을 배치했다.

**세로로 자르면 얼굴과 시그니처 포즈가 화면 밖으로 나간다.**
쇼츠는 처음부터 9:16 으로 만든다. `bible/characters.json` 의 `style_tag_shorts` 가
그 태그다 — 세로 비율에 더해 «인물을 가운데, 머리 위 여백 넉넉히, 배경은 단순하게,
가장자리에는 중요한 것을 두지 않는다» 가 들어 있다.

## 비율은 프롬프트가 아니라 설정이다

가장 자주 틀리는 대목이다.

프롬프트에 `vertical 9:16 composition` 이라고 적혀 있어도 **이미지가 세로로 나오지 않는다.**
그 문구는 «인물을 세로 화면에 맞게 배치하라»는 **구도 힌트**일 뿐이고,
실제 캔버스 크기는 **생성 화면의 비율(Aspect ratio) 설정**이 정한다.

순서가 이렇다.

1. 이미지 생성 화면에서 비율을 **9:16**(또는 Portrait / 세로)로 바꾼다
2. 그 상태에서 이미지 프롬프트를 붙여 넣고 생성한다
3. 나온 세로 이미지를 **영상 생성의 시작 이미지**로 넣는다

3번이 중요하다. image2video 는 넣은 이미지의 비율을 그대로 따라간다.
**이미지만 세로로 뽑으면 영상은 자동으로 세로가 된다** — 영상 단계에서 따로 만질 것이 없다.

이미 16:9 로 뽑은 것은 다시 뽑아야 한다. 잘라서는 못 쓴다.

## 규격

`shorts_format.json` — 본편(`format.json`)과 별개다.

| | 값 | 이유 |
|---|---|---|
| 화면비 | 9:16 | |
| 길이 | 14~22초 (기본 18초) | 유아·아동은 짧을수록 끝까지 본다. 끝까지 본 비율이 노출을 결정한다 |
| 컷 | 3~5개 (기본 4개) | |
| 클립 | 4~5초 | 본편과 같다. image2video 는 그 이상에서 얼굴이 무너진다 |
| 대사 | 최대 3줄 | 쇼츠에 대사가 많으면 안 읽힌다 |
| 첫 컷 | 반드시 훅 | 1초 안에 얼굴이나 큰 동작이 없으면 넘겨진다 |

`scripts/check_shorts.py` 가 검사한다.

## 만든 것 22편

| 종류 | 편수 | 무엇 |
|---|---|---|
| **캐릭터 소개** `C01~C06` | 6 | 23초 · 얼굴 → 그 아이를 정의하는 행동 → 무리 안에서의 자리 → 자기 집 → 이름과 한마디 |
| **예고편** `T01~T10` | 10 | 23초 · 위기 → 상황 → **막힌 순간** → 실마리 → 제목. 결말은 감춘다 |
| **파워** `P01~P03` | 3 | 23초 · 능력만 보여주면 «그래서 뭐»가 된다. 그 힘이 **무엇을 했는지**까지 |
| **오늘 한마디** `D01~D03` | 3 | 30초 · 반복 포맷. 상황 → 문제 → 전환점 → 해결 → 한마디 |

### 순서

**캐릭터 소개 6편을 먼저 올린다.** 본편이 아직 없는 채널에서는 이게 가장 효율이 좋다.
얼굴을 먼저 각인시켜 두면 본편이 올라갔을 때 클릭률이 다르다. 마스터 시트로 이미
잡혀 있는 캐릭터라 새로 설계할 것도 없다.

그다음 **예고편**을 본편 공개에 맞춰 하나씩, **파워**는 사이사이에 끼워 넣는다.

## 반복 포맷 — 「쿵쿵이의 오늘 한마디」

쇼츠 채널을 실제로 키우는 건 일회성 영상이 아니라 **반복 포맷**이다.
구독자가 다음 편을 예상할 수 있어야 한다.

### 처음엔 너무 짧았다

처음엔 4컷 18초로 만들었는데, 그날의 장면이 **한 컷뿐**이라 실패했다.
4화 편을 보면 자동차가 잠깐 나오다가 갑자기 «함께 나누면 재미도 두 배»가 나온다.
**무엇을 나눴는지, 왜 그게 두 배인지가 화면에 없다.** 교훈이 엉뚱하게 들린다.

교훈으로 끝나는 형식은 **그 앞에 이야기가 있어야 한다.**
7컷 30초로 늘리고 컷2~5 를 상황 · 문제 · 전환점 · 해결로 나눴다.

```
컷1  쿵쿵이가 화면 아래에서 쏙 올라온다        ← 【고정】 매 편 같음
컷2  상황    — 무슨 일이 벌어지고 있는지        ← 그 화의 이야기
컷3  문제    — 무엇이 잘못됐는지               ← 그 화의 이야기
컷4  전환점  — 누가 무엇을 했는지              ← 그 화의 이야기
컷5  해결    — 그래서 어떻게 됐는지            ← 그 화의 이야기
컷6  시그니처 포즈 + 오늘의 한마디             ← 【고정】 포즈 고정, 대사만 바꿈
컷7  손 흔드는 엔드 카드                       ← 【고정】 매 편 같음
```

4화 편이라면 컷2 자랑 → 컷3 거절당한 후안 → 컷4 루카가 내민다 → 컷5 나란히 달린다.
**여기까지 보고 나야 «두 배»라는 말이 들린다.**

**한마디는 각 화의 교훈을 그대로 쓴다.** `episodes.json` 의 `moral` 이 40화까지
전부 있으므로 **40편이 이미 준비되어 있는 셈이다.** 그 화의 컷 리스트에서 상황·문제·
전환점·해결에 해당하는 장면 넷을 골라 세로로 다시 뽑으면 된다.

고정 컷 세 개(1·6·7)는 한 번 잘 뽑아 두면 계속 재사용한다 — 매 편 다시 만들 필요가 없다.
**편당 실제 생성은 네 컷**이다. 4컷짜리 쇼츠를 통째로 새로 만드는 것과 같은 비용으로
이야기가 있는 30초를 얻는다.

## 만드는 법

```bash
python3 scripts/build_shorts.py            # 프롬프트 생성 (전체)
python3 scripts/build_shorts.py C01        # 하나만
python3 scripts/check_shorts.py            # 규격 검사
python3 site/make_shorts.py                # 복붙용 페이지 → site/dist/kungkung_shorts.html
```

캐릭터는 본편과 똑같이 **OpenArt Characters 트리거 워드**로 고정된다.
프롬프트 안의 한글 이름이 그 트리거 워드다. **외모를 따로 적으면 안 된다** —
적는 순간 등록된 얼굴을 덮어쓴다.

OpenArt 밖에서 만들어야 할 때는 `--mode sheet` 를 준다. 트리거 워드 대신
영어 `ref_tag` 가 들어가고, 마스터 시트를 레퍼런스 이미지로 첨부해야 얼굴이 고정된다.

## 자막

본편과 같은 도구를 쓰되 세로 규격으로 스타일을 따로 잡아야 한다.
`subtitle_style.json` 의 `video` 를 `1080 × 1920` 으로 바꾸고 글자 크기를 키운다.
쇼츠는 세로라 한 줄에 들어가는 글자 수가 적다 — `max_chars_per_line` 을 12~14 로 줄인다.
