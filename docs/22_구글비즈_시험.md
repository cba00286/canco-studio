# 구글 Vids(Omni 1.2 Flash) 쿵쿵 시험

목적: 쿵쿵 얼굴이 유지되는지, 한국어 대사 입모양이 맞는지 본다. 무료 월 3개 중 1~2개만 쓴다.
이 시험은 Vids 웹(vids.new, 데스크톱)에서 사람이 직접 한다. 구글 로그인이 필요하다.

## 준비물
- 참조 이미지: `episodes/ep1/reference/kungkung_official_reference.png`
  - 쿵쿵 단독 컷이 더 좋다. 오른쪽 전신을 잘라 쓰거나, 쿵쿵 마스터 시트가 있으면 그걸 쓴다.
- 비율 16:9, 길이 8~15초

## 시험 1 — 쿵쿵 얼굴 유지 + 한국어 대사 (EN-01)
Vids → AI 생성 동영상 만들기 → 소재에 참조 이미지 업로드 → 아래 프롬프트 붙여 넣기

```
참조 이미지의 캐릭터를 그대로 사용한다. 얼굴, 뿔 세 개, 목 프릴, 꽃무늬 반다나를 바꾸지 않는다.
[외형] 민트색 아기 트리케라톱스, 복숭아빛 작은 뿔 세 개, 베이지 목 프릴, 목에 꽃무늬 아이보리 반다나. 뿔 세 개·목 프릴·꽃무늬 반다나는 처음부터 끝까지 그대로 유지된다.
[동작] 아기가 수줍게 고개를 숙이고 발끝으로 땅을 문지르다가 고개를 들며 자랑스러운 미소를 띤다.
[대사] 아기 공룡이 입을 크게 벌려 또박또박 한국어로 말한다: "헤헤, 내가 친구들을 지켜줄게, 쿵쿵!" 다섯 살 남자아이 목소리, 높고 둥글고 살짝 허스키하게, 문장 끝을 올려서.
[소리] 그 장면의 자연스러운 환경음만. 배경음악 없이 목소리와 효과음만.
[화풍] 픽사 스타일 3D 애니메이션, 부드러운 서브서피스 산란과 따뜻한 시네마틱 조명, 둥글고 친근한 캐릭터 조형, 얕은 피사계 심도, 고급스러운 극장용 렌더링 품질.
```

## 판정표
| 항목 | 통과 기준 |
|---|---|
| 얼굴 | 뿔 3개, 목 프릴, 눈 모양이 참조와 같다 |
| 반다나 | 꽃무늬가 끝까지 유지된다 |
| 색 | 민트색이 노랗거나 짙게 변하지 않는다 |
| 화풍 | 픽사풍 3D, 실사로 흐르지 않는다 |
| 한국어 대사 | 대사를 말하고 입모양이 한국어에 맞는다 |
| 대사 정확도 | "헤헤, 내가 친구들을 지켜줄게, 쿵쿵!"이 그대로 나온다 |
| 연속성 | 시험 2(다른 컷)에서도 같은 쿵쿵이다 |
