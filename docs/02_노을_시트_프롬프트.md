# 노을 3D 마스터 시트 프롬프트

> 기존 6종 시트를 만든 것과 같은 형식으로 뽑는다.
> 데이터 원본은 `seasons/s2_new_character.json` 의 `sheets`.

## 먼저 — 라벨은 영어로 요청한다

기존 시트들의 한글 라벨이 상당수 깨져 있다.

```
북정한 암석 위상학       ← «복잡한 암석 위상학»
월드 징언 와이이프래임    ← «월드 정면 와이어프레임»
쿵쿵이 세부 와이어프E 및 토폴로지
```

생성 모델이 한글 글자를 제대로 못 그린다. **라벨을 영어로 받고 한글은 편집에서 얹는 편이
훨씬 깨끗하다.** 아래 프롬프트는 전부 영어 라벨로 요청하도록 써 두었다.

## 외모 확정

| 항목 | 값 |
|---|---|
| 종 | 붉은여우 |
| 키 | **130cm** — 루카 160 > 쿵쿵 140 > **노을 130** > 루비 120 > 티니 110 > 미미 105 > 후안 100 |
| 털 | 따뜻한 적갈색(russet), 주둥이·가슴·배는 크림 화이트 |
| 다리 | 네 다리 모두 검은 스타킹 무늬 |
| 꼬리 | 크고 풍성하며 끝이 흰색 |
| 귀 | 길고 뾰족, 가장자리는 어둡고 안쪽은 크림색 |
| 눈 | 날카로운 호박색(amber) |
| 옷 | **짧은 숲색 후드 조끼**, 목에 나무 토글 하나 |
| 소품 | 한쪽 허리에 작은 가죽 가방 |
| 표정 | 웃지 않는다. 차분하고 지켜보는 얼굴 |

> **긴 망토가 아니라 짧은 후드 조끼로 정했다.** 망토는 컷마다 흐르는 모양이 달라져서
> 30화 동안 일관성이 무너진다. 후드는 «후드를 눌러쓰고 말한다»는 시그니처에 필요하므로 남긴다.

## 1. 종합 마스터 시트

기존 6종과 같은 판형이다. 이걸 먼저 뽑는다.

```
A comprehensive 3D character model sheet for a children's animation series, laid out on a soft light-blue gradient background. Title at the top reads "Noeul (Fox)" with a subtitle line, and a height ruler down the left edge marked 0 to 130 with the character standing against it at 130cm.

CHARACTER: Noeul, a young red fox cub in Pixar/DreamWorks 3D animation style — warm russet fur with visible soft fluff, a cream-white muzzle, chest and belly, black stockings on all four legs, a large bushy tail with a white tip, tall pointed ears with dark edges and cream inner fur, sharp amber eyes with bright catchlights, a small dark nose. She wears a short forest-green hooded vest fastened with one wooden toggle at the collar, and a small leather satchel on one hip. Calm, watchful, slightly reserved expression — not smiling.

LAYOUT: large FRONT view on the left against the height ruler. To the right, LEFT SIDE and RIGHT SIDE views, and a BACK view. Below, smaller TOP and BOTTOM views and a head CLOSE-UP in a rounded frame. On the right side, FULL WIREFRAME and head WIREFRAME renders in clean line art. Bottom-right panel boxed with a label, containing detail studies: full body wireframe, head wireframe, the hooded vest fabric, a paw pad, and the bushy tail. Each view labelled in small clean English text.

Consistent character design across every view. Even studio lighting, no harsh shadows, high detail fur texture, family animation quality.
```

## 2. 다각도 시트

**1번 결과를 레퍼런스로 붙이고** 생성한다. OpenArt Characters 등록에 쓴다.

```
Character turnaround sheet of the character in the reference image: front view, three-quarter front view, side profile and back view, standing in a neutral relaxed pose, full body, identical character design in all four views, evenly lit on a plain light gray background, no text, no labels
```

## 3. 표정 시트

같이 등록하면 정확도가 올라간다. 마지막 «진짜 웃음» 하나가 중요하다 —
17화에서 처음 웃는 장면에 쓴다.

```
Expression sheet of the character in the reference image: six head-and-shoulders portraits in a grid — neutral and watchful, a small reluctant almost-smile, surprised, looking away uncomfortably, quietly determined, and one genuine open laugh — identical character design in every portrait, evenly lit on a plain light gray background, no text
```

## 4. 집 — 언덕 위 굴

다른 여섯 집과 같은 판형.

```
A comprehensive 3D environment model sheet for a children's animation series, on a light-blue gradient background. Title reads "Noeul's Hillside Den".

SUBJECT: a small fox den dug into a grassy hillside on the northern edge of a forest village. A narrow round doorway framed with stacked flat stones, worn steps leading up to it, tufts of grass and small wildflowers on the slope. Right side panels: wireframe topology of the hillside and the lookout post, plus texture close-ups of soil, grass and weathered wood. Labels in small clean English text.
```

## 순서

1. **1번 종합 시트**를 뽑는다. 마음에 들 때까지 반복한다 — 여기서 확정된 얼굴이 30화를 간다
2. 확정본을 레퍼런스로 **2번 다각도 · 3번 표정**을 뽑는다
3. 세 장을 **OpenArt Characters에 «노을»로 등록**한다. 기존 여섯과 같은 방식이다
4. 등록 후 `characters.json` 의 `trigger` 에 «노을» 을 넣고
   `python3 scripts/build_ref_prompts.py` 를 돌리면 프롬프트에 반영된다
5. **4번 집 · 5번 키 도감**은 급하지 않다. 11화 대본을 쓸 때쯤 필요하다

## 등록 후 확인

```bash
python3 scripts/check_ost.py ep1     # OST
ls episodes/ep1/reference/sheets/     # 시트
```

노을 시트는 `reference/sheets/` 에 넣으면 된다. 파일 이름에 «노을» 이나 «noeul» 이
들어 있으면 사이트 빌더가 찾는다.
