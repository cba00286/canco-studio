# 노을 3D 마스터 시트 프롬프트

> 기존 6종 시트를 만든 것과 같은 형식으로 뽑는다.
> 데이터 원본은 `seasons/s2_new_character.json` 의 `sheets`.

## 먼저 — 라벨은 영어로 요청한다

기존 시트들의 한글 라벨이 상당수 깨져 있다.

```
북정한 암석 위상학       ← «복잡한 암석 위상학»
월드 징언 와이이프래임    ← «월드 정면 와이어프레임»
쿵쿵이 세부 와이어프E 및 토폴로지
```

생성 모델이 한글 글자를 제대로 못 그린다. **라벨을 영어로 받고 한글은 편집에서 얹는 편이
훨씬 깨끗하다.** 아래 프롬프트는 전부 영어 라벨로 요청하도록 써 두었다.

## 외모 확정

| 항목 | 값 |
|---|---|
| 종 | 붉은여우 |
| 키 | **130cm** — 루카 160 > 쿵쿵 140 > **노을 130** > 루비 120 > 티니 110 > 미미 105 > 후안 100 |
| 털 | 따뜻한 적갈색(russet), 주둥이·가슴·배는 크림 화이트 |
| 다리 | 네 다리 모두 검은 스타킹 무늬 |
| 꼬리 | 크고 풍성하며 끝이 흰색 |
| 귀 | 길고 뾰족, 가장자리는 어둡고 안쪽은 크림색 |
| 눈 | 날카로운 호박색(amber) |
| 옷 | **짧은 숲색 후드 조끼**, 목에 나무 토글 하나 |
| 소품 | 한쪽 허리에 작은 가죽 가방 |
| 표정 | 웃지 않는다. 차분하고 지켜보는 얼굴 |

> **긴 망토가 아니라 짧은 후드 조끼로 정했다.** 망토는 컷마다 흐르는 모양이 달라져서
> 30화 동안 일관성이 무너진다. 후드는 «후드를 눌러쓰고 말한다»는 시그니처에 필요하므로 남긴다.

## 4. 집 — 언덕 위 굴

**240cm W × 220cm H × 200cm D** · 다른 여섯 집과 같은 판형이다.

| 항목 | 값 |
|---|---|
| 이름 | 언덕 위 굴 (Hillside Den) |
| 크기 | 240cm W × 220cm H × 200cm D |
| 위치 | 마을이 다 내려다보이는 북쪽 언덕 — 마을 안이지만 가장자리 |
| 방 | 기록의 방 (가장 크다) · 작업 공방 · 식량 저장고 · 아늑한 잠자리 |

집이 성격을 그대로 말한다 — **마을 안이지만 가장자리**이고, **모두가 내려다보이는** 높은 곳이다.
끼고 싶으면서도 거리를 두는 위치 그대로다.

그리고 여섯 집 중 유일하게 **「기록의 방」이 가장 큰 집**이다. 다른 집들은 작업 공방이나
식량 저장고가 중심인데, 노을의 집은 벽이 온통 직접 그린 지도와 표식으로 덮여 있다.
13화에서 올챙이를 매일 기록하던 수첩, 23화에서 다람쥐 가족 찾을 길을 그려 준 지도,
39화에서 선물로 건네는 「여섯의 얼굴을 그린 지도」가 전부 이 방에서 나온다.

## 순서

1. **1번 종합 시트**를 뽑는다. 마음에 들 때까지 반복한다 — 여기서 확정된 얼굴이 30화를 간다
2. 확정본을 레퍼런스로 **2번 다각도 · 3번 표정**을 뽑는다
3. 세 장을 **OpenArt Characters에 «노을»로 등록**한다. 기존 여섯과 같은 방식이다
4. 등록 후 `characters.json` 의 `trigger` 에 «노을» 을 넣고
   `python3 scripts/build_ref_prompts.py` 를 돌리면 프롬프트에 반영된다
5. **4번 집 · 5번 키 도감**은 급하지 않다. 11화 대본을 쓸 때쯤 필요하다

## 등록 후 확인

```bash
python3 scripts/check_ost.py ep1     # OST
ls episodes/ep1/reference/sheets/     # 시트
```

노을 시트는 `reference/sheets/` 에 넣으면 된다. 파일 이름에 «노을» 이나 «noeul» 이
들어 있으면 사이트 빌더가 찾는다.
