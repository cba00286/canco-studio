# 19. 지식재산 보호 — 캐릭터를 도용당하지 않으려면

캐릭터 사업에서 도용을 막는 것은 **저작권 하나가 아니라 세 겹**이다.
겹마다 막는 것이 다르고, 이 작품은 AI 생성물이라 함정이 하나 더 있다.

| 겹 | 무엇을 막나 | 강도 |
|---|---|---|
| **상표권** | 이름·로고를 **비슷하게라도** 쓰는 것 | 가장 세다. 굿즈·채널명 싸움은 여기서 갈린다 |
| **저작권** | 설정과 이야기를 **베끼는** 것 | 자동으로 생긴다. 등록은 증거를 미리 확보하는 것 |
| **디자인권** | 인형·문구의 **형태**를 베끼는 것 | 굿즈를 낼 때만 |

## AI 생성물이라 생기는 함정

한국 저작권법은 **인간의 창작적 기여**가 있어야 저작물로 본다.
프롬프트만 넣어서 나온 그림은, 프롬프트를 아무리 정교하게 짜도
**저작물로 보호받지 못한다.** 문체부 「생성형 AI 저작권 안내서」(2023.12) 기준이다.

한국저작권위원회 등록 때도 **AI 생성 부분을 표시**해야 하고, 그 부분은
등록에서 빠진다. 숨기고 등록하면 나중에 등록이 뒤집힌다.

**그런데 이 작품에서 사람이 만든 부분은 아주 많다.** 그쪽이 진짜 방어선이다.

| 보호가 강한 것 (사람) | 보호가 약한 것 (생성기) |
|---|---|
| 캐릭터 이름·성격·MBTI·목소리·꿈·두려움 | 마스터 시트 이미지 |
| 집 구조·키 도감·세계관·능력 체계 | 컷 키프레임 이미지 |
| 40화 줄거리와 전 컷 대사 | 컷 영상 클립 |
| 2,518컷의 컷 분할·연결·구도 설계 | 클립 안의 목소리·효과음 |
| 장면별 소리 설계, 자막, 편집 | |

> **이 작품의 값어치는 그림이 아니라 설정과 이야기에 있다.**
> 남이 민트색 아기 공룡을 그리는 것은 막기 어려워도,
> 「뿔에서 빛을 내어 친구를 지키는 다섯 살 아기 트리케라톱스」라는 캐릭터를
> 가져가는 것은 막을 수 있다.

**그림 쪽도 강하게 만들려면** 마스터 시트를 사람이 직접 리터치하거나 원화를
손으로 한 장 그려 두고, **그 파일도 저장소에 커밋해서 이력을 남긴다.**
「AI는 채색 도구였다」는 근거가 되고, 실무에서 효과가 가장 크다.

## 이 저장소가 이미 증거다

커밋마다 GitHub 서버가 시각을 찍어 두었으므로, **제3자가 보관하는 시계열
기록**이 이미 있다. 커밋 해시는 그 시점의 저장소 내용 전체에 대한 지문이라,
나중에 내용을 고치면 해시가 달라져 위조가 드러난다.

**그래서 히스토리를 절대 다시 쓰지 않는다.** `git rebase`, 강제 푸시 금지.
이건 나중에 돈으로 살 수 없는 자산이다.

## 만들어 두는 것

```
python3 scripts/build_ip_pack.py --pdf
```

`ip/` 에 세 가지가 나온다. 커밋 이력에서 자동으로 만들어지므로,
내용이 늘면 다시 돌려서 갱신한다.

| 파일 | 쓰임 |
|---|---|
| `창작이력_증빙.pdf` | **저작권 등록 신청서에 첨부한다.** 캐릭터 설정 원문, 40화·쇼츠 목록, 각 항목이 저장소에 처음 들어온 날짜와 커밋 해시, AI 사용 구분표 |
| `창작이력_증빙.html` | 같은 내용. 브라우저에서 「인쇄 → PDF」 해도 된다 |
| `창작이력_증빙.json` | 기계가 읽는 형태 |

`ip/상표출원_준비.md` 는 손으로 쓴 문서다 — 선행상표 검색어, 류별 지정상품
문안, 순서와 예산. 출원할 때 그대로 보고 따라 하면 된다.

## 하는 순서

1. **KIPRIS 선행상표 검색** — 「쿵쿵이」가 이미 등록돼 있으면 이름부터 다시 정해야 한다. 무엇보다 먼저
2. **상표 출원** 41류·28류 — **먼저 낸 사람이 이긴다.** 공개 전에 내는 것이 가장 안전하다
3. **저작권 등록** ㉠ 캐릭터 바이블 · ㉡ 시나리오 — `창작이력_증빙.pdf` 첨부
4. **유튜브 공개**
5. **저작권 등록** ㉤ 완성 영상 — 화별로, 공표 후 1년 안에
6. **디자인권** — 굿즈를 낼 거면 공개 후 **12개월 안에**

저작권 등록의 진짜 실익은 **법정손해배상**이다(저작권법 제125조의2).
실손해를 증명하지 못해도 저작물당 최대 1천만원, 영리 목적 고의 침해는
5천만원까지 청구할 수 있다. **단 침해가 일어나기 전에 등록돼 있어야 한다.**
이것이 미리 등록하는 이유다.
