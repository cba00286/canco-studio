# 소리 — 효과음 · 환경음 · BGM

영상이 끊겨 보이는 이유는 대개 그림이 아니라 **소리**다.
컷이 바뀔 때 배경 소리가 같이 끊기면, 이어 붙였다는 게 그림보다 먼저 들린다.

## 네 겹으로 쌓는다

| 겹 | 무엇 | 언제 바뀌나 | 레벨 |
|---|---|---|---|
| 1 | 나레이션 · 대사 | 컷마다 | -6 dBFS |
| 2 | 효과음 | 컷 안의 동작에 맞춰 | -14 dBFS |
| 3 | BGM | **장면(SC1~EN)마다** | -22 dBFS |
| 4 | 환경음 | **장면마다** | -30 dBFS |

**환경음은 컷마다 바꾸지 않는다.** 한 장면 내내 같은 소리가 깔려 있어야
컷이 넘어가도 «같은 곳에 있다»는 느낌이 유지된다. 이게 컷 전환 효과보다
훨씬 크게 작용한다.

## 어디에 뭐가 들어가는지

컷 리스트에 이미 다 적혀 있다.

- **대본집** (`docs/대본_시즌N.md`) — 장면 제목 밑에 `소리` 줄, 컷마다 `*소리 —*` 줄
- **컷 시트** (`site/dist/kungkung_epN_sheet.html`) — 장면마다 파란 띠, 컷마다 태그

배정은 `scripts/build_audio.py` 가 `bible/audio.json` 을 보고 자동으로 한다.
틀린 장면이 있으면 그 화의 `shots_v2.json` 에 `audio_overrides` 를 넣는다.

```json
"audio_overrides": {
  "SC3": { "amb": "동굴", "bgm": "신비_경이", "weather": "" }
}
```

`weather` 에 빈 문자열을 넣으면 «날씨 없음»이다. 고치고 나서
`python3 scripts/build_audio.py --episode ep12` 를 다시 돌리면 된다.

## 소리 파일 받기

```
python3 scripts/mix_audio.py --episode ep12 --list
```

받아야 할 파일이 검색어까지 같이 나온다. 폴더는 이렇게 만든다.

```
sound/bgm/일상_밝음.mp3
sound/amb/숲_낮.mp3
sound/sfx/발소리_풀.wav
sound/sig/쿵쿵_파워.wav
```

**파일 이름은 목록에 나온 이름과 똑같아야 한다.** 확장자는 wav · mp3 · m4a
아무거나 된다. 다 모으고 나서 확인:

```
python3 scripts/mix_audio.py --episode ep12 --sound sound --check
```

### 어디서 받나

| 곳 | 라이선스 | 메모 |
|---|---|---|
| 유튜브 오디오 보관함 | 유튜브 안에서 자유 | **가장 안전하다.** 유튜브에만 올릴 거면 여기부터 |
| Pixabay Audio | CC0 | 표시 필요 없음 |
| Freesound | 소리마다 다름 | **CC0 필터를 켜고 받을 것** |

저작자 표시가 필요한 소리는 쓰지 말 것. 40화까지 가면 표시를 관리할 수 없다.

## 합치기

```
# 1) 소리 트랙을 만든다
python3 scripts/mix_audio.py --episode ep12 --sound sound --out ep12_audio.m4a

# 2) 영상에 붙인다
python3 scripts/render_episode.py --episode episodes/ep12 \
    --clips 'outputs/ep12/*.mp4' --audio-track ep12_audio.m4a
```

`mix_audio.py` 가 하는 일:

- 장면마다 환경음과 BGM 을 잘라 넣고, 장면이 바뀔 때 0.5초 크로스페이드
- 컷이 시작하는 시각에 효과음을 하나씩 (동작보다 0.12초 늦게 — 그래야 자연스럽다)
- 능력 컷에 시그니처 소리
- 마지막에 -14 LUFS 로 정규화 (유튜브 기준)

없는 파일은 그 자리를 비우고 계속 간다. **다 모으기 전에도 들어 볼 수 있다.**

### 말소리를 녹음했으면

```
python3 scripts/mix_audio.py --episode ep12 --voice ep12_narration.wav --out ep12_audio.m4a
```

말이 나오는 동안 BGM 과 환경음이 자동으로 눌린다(사이드체인 덕킹).
녹음이 없으면 그냥 빼면 된다 — 덕킹만 안 할 뿐이다.

### 실측 길이로 맞추기

컷 전환(xfade)을 쓰면 완성본이 대본보다 짧아진다. `render_episode.py` 가
실측 길이를 재서 자막을 맞추는 것과 같은 이유로, 소리도 실측으로 맞춰야 한다.

```
python3 scripts/mix_audio.py --episode ep12 --durations 4.9,3.9,4.8,... --out ep12_audio.m4a
```

## 쿵쿵이의 능력 소리는 40화 내내 고정한다

`bible/audio.json` 의 `signature` 여섯 개다. 화마다 다르게 만들면
같은 능력으로 안 들린다. 무료 음원 하나를 그대로 쓰기보다 두세 개를
겹쳐 만드는 편이 낫다 — 구성은 바이블에 적어 두었다.

| 소리 | 핵심 |
|---|---|
| `쿵쿵_파워` | 저음 임팩트 + 상승 스윕 + 럼블 꼬리. 시리즈에서 가장 큰 효과음 |
| `쿵쿵_온기` | **어택이 없다.** 빛이 차오르는 속도로 소리도 차오른다 |
| `쿵쿵_바람` | 상승 휘슬 + 도는 공기(유지). 끝날 때 아래로 풀린다 |
| `쿵쿵_자장가` | 글로켄슈필이 느리게 내려간다. 가장 작게 |
| `쿵쿵_방어막` | 저음 붐 + 돔이 닫히는 소리 + 유리 shimmer(유지) |
| `뿔_반응` | **임팩트가 없다.** 36·40화 두 컷뿐. 있는지 없는지 헷갈릴 만큼 작게 |

`뿔_반응` 은 쿵쿵이 쓰는 게 아니라 저절로 반응하는 것이다. «시작»하는
소리가 들리면 안 된다 — 그러면 능력처럼 들리고, 40화의 복선이 죽는다.

## 지킬 것 일곱 가지

1. **환경음은 장면 안에서 끊지 않는다.** 장면이 바뀔 때만 0.5초 크로스페이드.
2. **BGM 은 장면당 한 곡.** 한 장면 안에서 곡을 바꿔야 한다면 그건 장면을 나눠야 한다는 뜻이다.
3. **말이 있는 컷에는 효과음을 하나만.** 겹치면 둘 다 안 들린다.
4. **능력 컷에서는 BGM 을 6 dB 더 내린다.** 시그니처 소리가 들려야 한다.
5. **쿵쿵의 «지켜줄게» 한마디 컷은 거의 무음으로.** 그 말만 들리게 한다.
6. **타이틀 카드에는 엔딩 테마만.** 환경음도 효과음도 넣지 않는다.
7. **저작자 표시가 필요한 소리는 쓰지 않는다.**

3·5·6번은 `build_audio.py` 가 자동으로 지킨다. 1·2번은 `mix_audio.py` 가 지킨다.
4번은 지금 수동이다 — 능력 컷에서 BGM 을 손으로 조금 더 내려야 한다.
