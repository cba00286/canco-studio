# 12. 자막과 렌더 — OpenArt 밖에서 하는 일

## 왜 밖에서 하나

OpenArt는 **생성** 도구다. 자막 기능은 구색만 있다 — 테두리 색을 지정할 수 없고,
폰트가 `sans-serif / Inter / Noto Sans / Noto Serif` 넷뿐이고, 미리보기가 없다.
`Inter`에는 한글 글리프가 아예 없어서 고르면 한글이 대체 폰트로 깨진다.

기능 문제와 별개로, **컷마다 자막을 구우면 파이프라인이 망가진다.**
1화가 60컷이므로:

- 오타 하나 고치려면 그 컷을 재생성해야 한다 → 크레딧 소모
- 컷 순서·길이를 바꾸면 자막 타이밍이 전부 깨진다
- 자막 스타일을 바꾸면 60컷 전부 재작업

그래서 자막은 **클립을 다 이어붙인 최종 타임라인에 한 번** 얹는다.
크레딧 0, 워터마크 0, 몇 번을 다시 해도 공짜다.

## 도구

`ffmpeg` 하나면 된다. 오픈소스라 워터마크가 붙을 여지가 없고 상업적 사용도 자유롭다.

```bash
brew install ffmpeg          # macOS
winget install ffmpeg        # Windows
pip install imageio-ffmpeg   # 위가 안 되면 이걸로도 된다
```

`render_episode.py` 는 `FFMPEG` 환경변수 → `PATH` → `imageio-ffmpeg` 순으로 찾는다.

## 사용법

```bash
# 자막만 만들기 (규격 길이 기준)
python3 scripts/build_subtitles.py --episode episodes/ep1

# 클립을 이어붙이고 자막까지 굽기 (실측 길이 기준으로 자막 자동 재생성)
python3 scripts/render_episode.py --episode episodes/ep1 --clips ~/쿵쿵이/1화클립

# 배경음악까지
python3 scripts/render_episode.py --episode episodes/ep1 --clips ~/쿵쿵이/1화클립 \
  --audio "episodes/ep1/assets/ost/쿵쿵이와 친구들 메인 테마송.mp3" --music-volume 0.3

# 무엇을 실행할지 먼저 보기
python3 scripts/render_episode.py --episode episodes/ep1 --clips ... --dry-run
```

클립 파일명은 **컷 ID만 포함하면** 된다: `SC1-01.mp4`, `ep1_SC1-01_v2.mp4` 모두 인식한다.
같은 컷의 파일이 여러 개면 **가장 최근 파일**을 쓴다(재생성본 우선).

## 나오는 것

| 파일 | 용도 |
|---|---|
| `episodes/ep1/subtitles/ep1.ass` | 화면에 굽는 자막. 테두리·폰트·위치 전부 제어 |
| `episodes/ep1/subtitles/ep1.srt` | 유튜브 업로드용. 시청자가 켜고 끌 수 있다 |
| `episodes/ep1/render/durations.json` | 클립 실측 길이 |
| `episodes/ep1/ep1.mp4` | 최종본 |

**유튜브에는 둘 다 쓴다.** 화면에 구운 자막은 무조건 보이고,
`.srt` 는 자동 번역·검색·접근성에 쓰인다.

## 왜 실측 길이를 재나

`shots_v2.json` 의 `duration` 은 규격(4초 또는 5초)이다.
실제로 생성된 클립은 4.13초, 4.93초처럼 조금씩 다르게 나온다.
컷당 0.2초만 어긋나도 60컷이면 **마지막에 12초가 밀린다.**

`render_episode.py` 는 클립 길이를 직접 재서 그 값으로 자막을 다시 만든다.
그래서 `build_subtitles.py` 를 단독으로 돌린 결과보다 항상 정확하다.

## 스타일 바꾸기

`subtitle_style.json` 하나만 고치면 전 화에 적용된다.

```jsonc
"대사": {
  "font": "NanumGothic",      // fonts/ 에 넣은 폰트의 "패밀리 이름"
  "size": 62,
  "fill": "#FFFFFF",          // 글자 색
  "outline": "#3B2314",       // ← 테두리 색. OpenArt 에 없던 바로 그것
  "outline_width": 5,         // ← 테두리 두께. 아동물은 4~6
  "shadow": 2,
  "margin_v": 78,             // 화면 아래에서 띄우는 거리
  "max_chars_per_line": 20,   // 한 줄 최대 글자수
  "max_lines": 2
}
```

색은 `#RRGGBB` 로 쓰면 된다. 스크립트가 ASS 형식(`&HAABBGGRR`, BGR 역순)으로 변환한다.

**나레이션과 대사가 다른 스타일이다.** 나레이션은 크림색 기울임, 대사는 흰색 정자체.

### 폰트 바꾸기

`fonts/` 에 `.ttf` 를 넣고 `font` 에 **패밀리 이름**을 적는다(파일명이 아니다).
아동 애니메이션이면 둥근 폰트가 어울린다 — 배민 주아체, Cafe24 Ssurround, 나눔손글씨 등.
저장소에는 **나눔고딕 Bold**(OFL 라이선스)가 기본으로 들어있다.

패밀리 이름을 모르겠으면:
```bash
python3 -c "from fontTools.ttLib import TTFont; f=TTFont('fonts/폰트.ttf'); \
print([r.toUnicode() for r in f['name'].names if r.nameID==1][:1])"
```

## 검증됨

`ffmpeg 7.0.2` (libass 포함) 로 실제 렌더까지 확인했다 — 14컷 이어붙이기,
실측 길이 보정(규격 대비 +0.02초), 한글 2줄 줄바꿈, 테두리·그림자 렌더 정상.
