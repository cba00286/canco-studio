# 계약 원본

서명·날인한 계약서를 스캔해서 여기에 넣고 **커밋한다.** 커밋 시각이 증거가 된다.

| 파일 | 무엇 |
|---|---|
| `저작권귀속_김성한.pdf` | 김성한 → 주식회사캔코 저작권 귀속 확인 및 양도 |
| `이사회의사록_저작권귀속.pdf` | 자기거래 승인 (상법 제398조) |
| `OST_외주계약_<작곡가>.pdf` | 작곡가와의 계약 |

**종이 원본은 따로 보관한다.** 스캔본만으로도 등록은 되지만, 분쟁에서는 원본이 세다.
