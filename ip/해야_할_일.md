## A. 지금 당장 (공개 전)

### ☐ A1. KIPRIS 선행상표 검색

**다른 무엇보다 먼저.** 「쿵쿵이」가 이미 등록돼 있으면 이름부터 다시 정해야 하고,
그러면 40화 대본의 대사까지 바뀐다. 검색어와 기록표는 `ip/상표출원_준비.md`.

> 이 작업 환경에서는 kipris.or.kr 접속이 차단돼 있어 **직접 하셔야 합니다.**

### ☐ A2. 권리자 명의 결정

출원서에 적을 이름이다. **나중에 바꾸면 이전 절차와 비용이 든다.**

| 선택 | 언제 |
|---|---|
| 개인 | 지금 혼자 하고, 당분간 법인 계획이 없다 |
| 법인 | 이미 사업자가 있거나 곧 만든다 |

법인을 만들 생각이 있으면 **처음부터 법인 명의로** 내는 것이 싸다.

### ☐ A3. 상표 출원 — 41류·28류

「쿵쿵이와 친구들」, 「쿵쿵이」 두 표장. 지정상품 문안은 `ip/상표출원_준비.md`에
복사해 쓸 수 있게 적어 두었다. **선출원주의라 공개 전에 내는 것이 가장 안전하다.**

### ☐ A4. 도메인·계정 선점

거의 공짜인데 뺏기면 되찾기가 어렵다. 같은 이름으로 한 번에 잡는다.

- [ ] 유튜브 핸들 `@...`
- [ ] 인스타그램 · 틱톡 · X
- [ ] 도메인 (`.com` / `.kr`) — 이미 `kungkungworld.com` 이 있으면 확인
- [ ] 네이버 · 카카오 채널

### ☐ A5. 저작권 등록 ㉠ 캐릭터 바이블 · ㉡ 시나리오

한국저작권위원회 `www.cros.or.kr`. `ip/창작이력_증빙.pdf` 를 첨부한다.
**AI 생성 부분을 반드시 표시한다** — 숨기면 나중에 등록이 뒤집힌다.

## B. 공개 전에 정리해 둘 것 — 나중에 터지는 것들

### ☐ B1. OST 권리 확인 ⚠️

`episodes/ep1/assets/ost/ost.json` 에 메인 테마송이 **Suno 생성**으로 기록돼 있다.
확인할 것:

- [ ] Suno 요금제가 **상업적 이용을 허용하는 등급**인가 (무료 등급은 대개 불가)
- [ ] 생성물의 권리가 누구에게 있는지 약관 확인
- [ ] 유튜브 수익화 시 문제가 없는지

**AI 생성 음악도 그림과 같은 문제가 있다** — 사람의 창작적 기여가 없으면
저작물이 아니다. 남이 그대로 가져다 써도 막기 어렵다.
테마송은 브랜드의 핵심이므로, 가능하면 **작곡가에게 편곡·재녹음을 맡기고
권리를 양도받는 것**을 권한다.

### ☐ B2. 효과음·환경음 라이선스 기록 ⚠️

`bible/audio.json` 에는 **검색어**만 있고 실제로 어디서 받았는지가 없다.
무료 음원도 라이선스가 제각각이고(CC0 / CC-BY / 상업 불가),
**유튜브 Content ID 클레임이 실제로 자주 들어온다.**

음원을 받을 때마다 `bible/audio_sources.json` 에 기록한다:

```json
{
  "충돌_쿵": {
    "출처": "Freesound",
    "URL": "https://freesound.org/s/000000/",
    "제작자": "...",
    "라이선스": "CC0",
    "받은날": "2026-09-06"
  }
}
```

`scripts/check_rights.py` 가 빠진 것을 잡아 준다.

### ☐ B3. 폰트 라이선스

자막에 나눔고딕(`fonts/NanumGothicBold.ttf`)을 쓴다. 나눔글꼴은 상업적 이용이
가능하지만, **다른 폰트를 추가로 쓸 때마다** 영상 임베딩 허용 여부를 확인한다.
로고에 쓰는 폰트는 특히 조심 — 상표 출원까지 가면 문제가 커진다.

### ☐ B4. OpenArt 이용약관

생성물의 **상업적 이용권**이 요금제에 포함되는지 확인한다. 무료·체험 등급은
제한이 있는 경우가 많다. 40화를 다 만든 뒤에 알면 늦는다.

### ☐ B5. 영상에 권리 표기

엔딩 카드에 `© 2026 <권리자명>. All rights reserved.` 를 넣는다.
`bible/rights.json` 에 권리자명을 채우면 자막에 자동으로 들어간다.

## 절대 하지 말 것

- **git 히스토리를 다시 쓰지 않는다.** `rebase`, 강제 푸시 금지.
  커밋 시각이 창작 시점의 증거이고, 이건 돈으로 살 수 없다
- **원화 스캔 원본을 지우지 않는다.** 채색본만 남기면 근거가 사라진다
- **AI 생성 부분을 숨기고 등록하지 않는다.** 나중에 등록이 뒤집힌다

> 법률 자문이 아니다. 출원 전에 변리사 확인을 권한다.
> 한국저작권위원회와 한국발명진흥회에서 공익변리사 무료 상담을 받을 수 있다.
