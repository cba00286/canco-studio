## B. 공개 전에 정리해 둘 것 — 나중에 터지는 것들

### ☐ B1. OST — 사람이 다시 만든다 (2026-09-09 결정)

메인 테마는 **Suno** 생성으로 확인됐다. AI 생성 음악은 인간의 창작적 기여가
없어 저작물이 아니다 — 남이 그대로 가져다 써도 막기 어렵고, 비슷한 프롬프트로
거의 같은 곡이 나올 수 있다. **40화의 대표곡을 그 상태로 둘 수 없다.**

그래서 **사람이 편곡·연주·녹음한 것으로 교체**하고, Suno 곡은 작곡가에게
방향을 전달하는 **내부 레퍼런스**로만 쓴다.

- [ ] 작곡가 후보에게 **신탁(KOMCA) 가입 여부**부터 묻는다 ⚠️
- [ ] 계약서에 **2차적저작물작성권 포함**을 명시한다 ⚠️
- [ ] → `ip/OST_외주_계약_체크리스트.md` 전체를 대조한다

**이 둘이 빠지면 돈을 내고도 권리를 못 갖는다.** 신탁 회원이면 저작재산권이
협회에 있어 양도가 안 되고, 2차적저작물작성권을 안 쓰면 오프닝·엔딩·능력 큐로
잘라 쓰는 것 자체가 막힌다.

> **가사는 이미 내 것이다.** 오프닝 「쿵! 쿵! 쿵쿵이」 가사는 직접 썼으므로
> 어문저작물로 온전히 보호된다. 저작권 등록 ㉠㉡ 에 함께 넣는다.

### ☐ B2. 효과음·환경음 라이선스 기록 ⚠️

`bible/audio.json` 에는 **검색어**만 있고 실제로 어디서 받았는지가 없다.
무료 음원도 라이선스가 제각각이고(CC0 / CC-BY / 상업 불가),
**유튜브 Content ID 클레임이 실제로 자주 들어온다.**

음원을 받을 때마다 `bible/audio_sources.json` 에 기록한다:

```json
{
  "충돌_쿵": {
    "출처": "Freesound",
    "URL": "https://freesound.org/s/000000/",
    "제작자": "...",
    "라이선스": "CC0",
    "받은날": "2026-09-06"
  }
}
```

`scripts/check_rights.py` 가 빠진 것을 잡아 준다.

### ☐ B3. 폰트 라이선스

자막에 나눔고딕(`fonts/NanumGothicBold.ttf`)을 쓴다. 나눔글꼴은 상업적 이용이
가능하지만, **다른 폰트를 추가로 쓸 때마다** 영상 임베딩 허용 여부를 확인한다.
로고에 쓰는 폰트는 특히 조심 — 상표 출원까지 가면 문제가 커진다.

### ☑ B4. OpenArt 이용약관 — 확인됨 (2026-09-09)

상업적 이용이 허용되는 요금제로 가입한 것을 확인했다.
**요금제를 낮추거나 해지하면 조건이 달라질 수 있으니** 등급을 바꿀 때 다시 본다.

### ☐ B5. 영상에 권리 표기

`bible/rights.json` 에 권리자명을 채우면 자막에 자동으로 들어간다.

## 절대 하지 말 것

- **git 히스토리를 다시 쓰지 않는다.** `rebase`, 강제 푸시 금지.
  커밋 시각이 창작 시점의 증거이고, 이건 돈으로 살 수 없다
- **원화 스캔 원본을 지우지 않는다.** 채색본만 남기면 근거가 사라진다
- **AI 생성 부분을 숨기고 등록하지 않는다.** 나중에 등록이 뒤집힌다
