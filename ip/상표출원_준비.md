# 상표 출원 준비 — 「쿵쿵이와 친구들」

저작권은 **베낀 것**만 막는다. 상표는 **비슷하기만 해도** 막는다.
캐릭터 사업에서 실제로 돈이 걸린 싸움(굿즈, 채널명, 라이선싱)은 거의 전부
상표로 갈린다. 그래서 순서상 저작권 등록보다 **상표가 먼저**다.

그리고 상표는 **먼저 낸 사람이 이긴다**(선출원주의). 유튜브에 공개한 뒤에
남이 먼저 출원해 버리면, 내가 만든 캐릭터인데도 이름을 못 쓰게 되는 일이
실제로 일어난다. **공개 전에 내는 것이 가장 안전하다.**

> 이 문서는 법률 자문이 아니다. 실제 출원 전에 변리사 확인을 권한다.
> 특허청·한국발명진흥회의 공익변리사 무료 상담을 쓸 수 있다.
> 관납료는 바뀌므로 출원 직전에 특허청 고시로 확인한다.

## 0. 제일 먼저 — 선행상표 검색

**이걸 안 하고 출원하면 돈만 버린다.** 「쿵쿵이」가 이미 등록돼 있으면
이름부터 다시 정해야 하므로, 다른 작업보다 먼저 확인한다.

`KIPRIS` (특허정보넷, `www.kipris.or.kr`) → 상표 검색

검색어는 이렇게 넣는다. **정확히 같은 것만 보면 안 되고 비슷한 것까지** 봐야 한다.

| 검색어 | 왜 |
|---|---|
| `쿵쿵이` | 그대로 |
| `쿵쿵` | 요부(핵심 부분)가 같으면 유사로 본다 |
| `쿵쿵이와 친구들` | 전체 |
| `쿵쿵*` | 앞부분이 같은 것 전부 |
| `KUNGKUNG` `KKUNGKKUNG` | 영문 음역. 호칭이 같으면 유사다 |
| 루카 · 후안 · 미미 · 티니 · 루비 · 노을 | 조연 이름. 흔한 이름일수록 선등록이 많다 |

- **41류와 28류를 중심으로** 본다. 다른 류에 같은 이름이 있어도 대개 상관없다.
- 등록만이 아니라 **출원 중(심사대기)** 인 건도 봐야 한다. 그쪽이 먼저다.
- 소멸·거절된 건은 걸림돌이 아니다. 다만 **왜 거절됐는지**는 읽어 볼 값어치가 있다.

아래 표를 채워 두면 나중에 변리사와 이야기할 때 그대로 쓴다.

| 검색어 | 검색일 | 결과 | 걸리는 건 | 판단 |
|---|---|---|---|---|
| **쿵쿵이** | **2026-09-06** | **선등록 없음** | 없음 | **출원 가능** |
| **쿵쿵이와 친구들** | **2026-09-06** | **선등록 없음** | 없음 | **출원 가능** |
| 쿵쿵 (단독) | | | | 아직 |
| 쿵쿵* (앞부분 일치) | | | | 아직 |
| KUNGKUNG / KKUNGKKUNG | | | | 아직 |
| 루카 · 후안 · 미미 · 티니 · 루비 · 노을 | | | | 아직 |

> 2026-09-06 본인 검색. 주 표장 두 개가 비어 있는 것을 확인했다.
> **남은 것 둘.** ① 「쿵쿵」 단독과 「쿵쿵*」 — 요부가 같으면 유사로 보므로
> 「쿵쿵랜드」 같은 게 있으면 걸릴 수 있다. ② **출원 중(심사대기) 건** —
> 등록만 보면 안 된다. 아직 등록 안 됐어도 먼저 낸 쪽이 이긴다.
> 이 둘까지 비어 있으면 사실상 깨끗하다.

**「노을」과 「루비」는 특히 조심한다.** 일반명사에 가까워서 선등록이 많고,
식별력도 약하다. 캐릭터 도형과 묶어서 내는 편이 낫다.

## 1. 출원할 표장

**문자와 도형을 따로 낸다.** 도형이 붙은 것만 내면, 이름만 베껴 쓰는 것을
막기 어렵다. 반대로 문자만 내면 그림을 베끼는 것을 못 막는다.

| 우선 | 표장 | 형태 | 비고 |
|---|---|---|---|
| **1** | 쿵쿵이와 친구들 | 문자 | 작품 제목이자 브랜드. 채널명 방어의 핵심 |
| **1** | 쿵쿵이 | 문자 | 주인공 단독. 굿즈에 제일 많이 박힌다 |
| **2** | (로고) | 도형 | 확정된 로고 이미지 |
| **2** | (쿵쿵이 정면 도안) | 도형 | 마스터 시트의 정면 컷 |
| 3 | 루카 · 후안 · 미미 · 티니 · 루비 · 노을 | 문자 | 조연. 예산이 되면 |

도형 상표는 **출원 시점에 확정된 그림**이어야 한다. 나중에 디자인을 바꾸면
바뀐 그림은 보호받지 못하므로, **마스터 시트를 확정한 뒤** 낸다.

## 3. 순서와 예산

돈이 한 번에 다 안 되면 **41류 → 28류 → 9류 → 16류 → 25류** 순서로 낸다.
41류는 사업의 본체이고 28류는 굿즈의 핵심이라 이 둘이 빠지면 의미가 적다.

| 단계 | 무엇 | 시점 |
|---|---|---|
| 1 | KIPRIS 선행상표 검색 | **지금** |
| 2 | 41류·28류 출원 (「쿵쿵이와 친구들」, 「쿵쿵이」) | 공개 **전** |
| 3 | 저작권 등록 ㉠ 바이블 · ㉡ 시나리오 | 공개 전 |
| 4 | 유튜브 공개 | |
| 5 | 나머지 류 출원, 도형 상표 | 마스터 시트 확정 후 |
| 6 | 저작권 등록 ㉤ 완성 영상 (화별) | 공표 후 1년 안 |
| 7 | 디자인권 (인형·문구를 낼 거면) | 공개 후 **12개월 안** — 넘기면 신규성을 잃는다 |

**비용은 「표장 × 류」로 는다.** 표장 2개 × 류 2개 = 출원 4건이다.
출원료 외에 등록 결정 뒤 설정등록료가 따로 든다. 심사에는 보통 1년 안팎이
걸리고, 급하면 우선심사를 신청할 수 있다(추가 비용). **정확한 금액은
특허청 `특허로`에서 출원 직전에 확인한다.**

## 4. 걸리기 쉬운 것

| 사유 | 내용 | 피하는 법 |
|---|---|---|
| 선출원·유사 | 이미 비슷한 게 있다 | 0번 검색을 제대로 한다 |
| 식별력 없음 | 흔한 말이라 누구 것도 아니다 | 「노을」 같은 건 도형과 묶어 낸다 |
| 사용의사 | 낼 생각도 없는 상품을 잔뜩 지정 | 실제로 할 것만 넣는다 |
| 저명상표 오인 | 유명 상표와 혼동 | 검색으로 확인 |

**공개 후 남이 먼저 출원한 경우**에도 방법이 없지는 않다. 내가 먼저 만들었다는
증거가 있으면 다툴 수 있고(무단 출원에 대한 이의신청·무효심판), 이때
`ip/창작이력_증빙.pdf` 와 저장소의 커밋 이력이 바로 그 증거가 된다.
다만 **이건 뒤집는 싸움이라 훨씬 비싸고 오래 걸린다.** 먼저 내는 게 낫다.

## 6. 특허로 출원 실무 — 처음 내는 사람 기준

온라인 출원은 특허청 `특허로`(`www.patent.go.kr`)에서 한다. 순서가 정해져 있고,
**앞 단계를 건너뛰면 다음이 안 된다.**

### ☐ 1) 특허고객번호(출원인코드) 발급

특허청에 나를 등록하는 번호다. 이게 없으면 출원 자체가 시작되지 않는다.
개인은 본인인증, 법인은 법인 정보로 신청한다. 발급까지 하루 이틀 걸리므로
**제일 먼저 신청해 두고 나머지를 준비한다.**

### ☐ 2) 인증서 등록

공동인증서 또는 금융인증서를 특허로에 등록한다. 출원서 제출과 수수료 납부에 쓴다.

### ☐ 3) 표장 준비

| 형태 | 준비물 |
|---|---|
| 문자 상표 | 텍스트만 있으면 된다. 「쿵쿵이와 친구들」 |
| 도형 상표 | **이미지 파일.** 배경 없이 깨끗하게, 규정 크기에 맞춰 |

도형 파일 규격(해상도·크기·형식)은 특허로 안내를 따른다. 규격이 안 맞으면
보정 통지가 오고 그만큼 늦어진다.

> **도형은 마스터 시트를 확정한 뒤에 낸다.** 나중에 그림을 바꾸면 바뀐 그림은
> 보호받지 못한다. 손으로 그린 원화가 있으면 그쪽이 더 좋다 → `docs/20_원화_작업.md`

### ☐ 4) 지정상품 고르기

특허로의 **「상품명칭 검색」에서 고시명칭을 골라 넣는다.** 직접 지어낸 상품명을
쓰면 심사관이 보정을 요구한다. 위 2절의 문안이 고시명칭 기준이다.

**한 류당 20개까지는 추가 요금이 없다.** 실제로 할 사업만 넣는다 —
낼 생각도 없는 상품을 잔뜩 지정하면 「사용의사 없음」으로 걸릴 수 있다.

### ☐ 5) 출원서 작성·제출

「상표법 제36조에 따른 상표등록출원서」. 표장 하나 × 류 하나가 출원 1건이다.
**표장 2개 × 류 2개 = 4건**이라는 뜻이다.

### ☐ 6) 수수료 납부

납부해야 출원일이 확정된다. **출원일이 곧 순위**이므로 미루지 않는다.

### ☐ 7) 심사 대기

보통 1년 안팎이 걸린다. 급하면 **우선심사**를 신청할 수 있다(추가 비용).
이미 사용 중이거나 사업이 임박한 경우가 우선심사 사유에 해당한다 —
유튜브 공개가 예정돼 있으면 신청해 볼 값어치가 있다.

중간에 **의견제출통지서**가 오면 기한 안에 답해야 한다. 놓치면 거절된다.
이 단계부터는 변리사를 쓰는 편이 낫다.

### ☐ 8) 등록 결정 → 설정등록료 납부

여기까지 내야 상표권이 생긴다. 존속기간 10년, 갱신하면 계속 유지된다.

## 7. 비용 감각

관납료는 **「표장 × 류」로 는다.** 표장 2개 × 2류 = 4건이다.
출원료와 별개로 등록 결정 뒤 설정등록료가 또 든다.

변리사를 쓰면 건당 대리인 비용이 붙지만, **거절 대응까지 생각하면 대개 남는다.**
특히 도형 상표와 의견제출 대응은 혼자 하기 어렵다.

예산이 빠듯하면 이 순서로 자른다.

1. **「쿵쿵이와 친구들」 문자 × 41류** — 이것 하나는 반드시
2. **「쿵쿵이」 문자 × 41류**
3. **「쿵쿵이」 문자 × 28류**
4. 나머지

> 정확한 금액은 출원 직전에 특허로에서 확인한다. 수수료는 개정된다.
> 한국발명진흥회의 **공익변리사 무료 상담**과 지역지식재산센터의
> 출원 지원 사업을 먼저 알아보면 비용을 크게 줄일 수 있다.
