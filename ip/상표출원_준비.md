# 상표 출원 준비 — 「쿵쿵이와 친구들」

저작권은 **베낀 것**만 막는다. 상표는 **비슷하기만 해도** 막는다.
캐릭터 사업에서 실제로 돈이 걸린 싸움(굿즈, 채널명, 라이선싱)은 거의 전부
상표로 갈린다. 그래서 순서상 저작권 등록보다 **상표가 먼저**다.

그리고 상표는 **먼저 낸 사람이 이긴다**(선출원주의). 유튜브에 공개한 뒤에
남이 먼저 출원해 버리면, 내가 만든 캐릭터인데도 이름을 못 쓰게 되는 일이
실제로 일어난다. **공개 전에 내는 것이 가장 안전하다.**

> 이 문서는 법률 자문이 아니다. 실제 출원 전에 변리사 확인을 권한다.
> 특허청·한국발명진흥회의 공익변리사 무료 상담을 쓸 수 있다.
> 관납료는 바뀌므로 출원 직전에 특허청 고시로 확인한다.

## 0. 제일 먼저 — 선행상표 검색

**이걸 안 하고 출원하면 돈만 버린다.** 「쿵쿵이」가 이미 등록돼 있으면
이름부터 다시 정해야 하므로, 다른 작업보다 먼저 확인한다.

`KIPRIS` (특허정보넷, `www.kipris.or.kr`) → 상표 검색

검색어는 이렇게 넣는다. **정확히 같은 것만 보면 안 되고 비슷한 것까지** 봐야 한다.

| 검색어 | 왜 |
|---|---|
| `쿵쿵이` | 그대로 |
| `쿵쿵` | 요부(핵심 부분)가 같으면 유사로 본다 |
| `쿵쿵이와 친구들` | 전체 |
| `쿵쿵*` | 앞부분이 같은 것 전부 |
| `KUNGKUNG` `KKUNGKKUNG` | 영문 음역. 호칭이 같으면 유사다 |
| 루카 · 후안 · 미미 · 티니 · 루비 · 노을 | 조연 이름. 흔한 이름일수록 선등록이 많다 |

- **41류와 28류를 중심으로** 본다. 다른 류에 같은 이름이 있어도 대개 상관없다.
- 등록만이 아니라 **출원 중(심사대기)** 인 건도 봐야 한다. 그쪽이 먼저다.
- 소멸·거절된 건은 걸림돌이 아니다. 다만 **왜 거절됐는지**는 읽어 볼 값어치가 있다.

아래 표를 채워 두면 나중에 변리사와 이야기할 때 그대로 쓴다.

| 검색어 | 검색일 | 결과 | 걸리는 건 | 판단 |
|---|---|---|---|---|
| 쿵쿵이 | | | | |
| 쿵쿵 | | | | |
| 쿵쿵이와 친구들 | | | | |
| KUNGKUNG | | | | |
| 루비 | | | | |
| 노을 | | | | |

**「노을」과 「루비」는 특히 조심한다.** 일반명사에 가까워서 선등록이 많고,
식별력도 약하다. 캐릭터 도형과 묶어서 내는 편이 낫다.

## 1. 출원할 표장

**문자와 도형을 따로 낸다.** 도형이 붙은 것만 내면, 이름만 베껴 쓰는 것을
막기 어렵다. 반대로 문자만 내면 그림을 베끼는 것을 못 막는다.

| 우선 | 표장 | 형태 | 비고 |
|---|---|---|---|
| **1** | 쿵쿵이와 친구들 | 문자 | 작품 제목이자 브랜드. 채널명 방어의 핵심 |
| **1** | 쿵쿵이 | 문자 | 주인공 단독. 굿즈에 제일 많이 박힌다 |
| **2** | (로고) | 도형 | 확정된 로고 이미지 |
| **2** | (쿵쿵이 정면 도안) | 도형 | 마스터 시트의 정면 컷 |
| 3 | 루카 · 후안 · 미미 · 티니 · 루비 · 노을 | 문자 | 조연. 예산이 되면 |

도형 상표는 **출원 시점에 확정된 그림**이어야 한다. 나중에 디자인을 바꾸면
바뀐 그림은 보호받지 못하므로, **마스터 시트를 확정한 뒤** 낸다.

## 3. 순서와 예산

돈이 한 번에 다 안 되면 **41류 → 28류 → 9류 → 16류 → 25류** 순서로 낸다.
41류는 사업의 본체이고 28류는 굿즈의 핵심이라 이 둘이 빠지면 의미가 적다.

| 단계 | 무엇 | 시점 |
|---|---|---|
| 1 | KIPRIS 선행상표 검색 | **지금** |
| 2 | 41류·28류 출원 (「쿵쿵이와 친구들」, 「쿵쿵이」) | 공개 **전** |
| 3 | 저작권 등록 ㉠ 바이블 · ㉡ 시나리오 | 공개 전 |
| 4 | 유튜브 공개 | |
| 5 | 나머지 류 출원, 도형 상표 | 마스터 시트 확정 후 |
| 6 | 저작권 등록 ㉤ 완성 영상 (화별) | 공표 후 1년 안 |
| 7 | 디자인권 (인형·문구를 낼 거면) | 공개 후 **12개월 안** — 넘기면 신규성을 잃는다 |

**비용은 「표장 × 류」로 는다.** 표장 2개 × 류 2개 = 출원 4건이다.
출원료 외에 등록 결정 뒤 설정등록료가 따로 든다. 심사에는 보통 1년 안팎이
걸리고, 급하면 우선심사를 신청할 수 있다(추가 비용). **정확한 금액은
특허청 `특허로`에서 출원 직전에 확인한다.**

## 4. 걸리기 쉬운 것

| 사유 | 내용 | 피하는 법 |
|---|---|---|
| 선출원·유사 | 이미 비슷한 게 있다 | 0번 검색을 제대로 한다 |
| 식별력 없음 | 흔한 말이라 누구 것도 아니다 | 「노을」 같은 건 도형과 묶어 낸다 |
| 사용의사 | 낼 생각도 없는 상품을 잔뜩 지정 | 실제로 할 것만 넣는다 |
| 저명상표 오인 | 유명 상표와 혼동 | 검색으로 확인 |

**공개 후 남이 먼저 출원한 경우**에도 방법이 없지는 않다. 내가 먼저 만들었다는
증거가 있으면 다툴 수 있고(무단 출원에 대한 이의신청·무효심판), 이때
`ip/창작이력_증빙.pdf` 와 저장소의 커밋 이력이 바로 그 증거가 된다.
다만 **이건 뒤집는 싸움이라 훨씬 비싸고 오래 걸린다.** 먼저 내는 게 낫다.
