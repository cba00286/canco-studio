# 미미 원화

**한 단계 끝날 때마다 커밋한다.** 커밋 시각이 그 단계의 날짜가 된다.
완성본 한 장보다 과정이 남은 여러 장이 훨씬 강하다.

| 파일 | 무엇 | 왜 |
|---|---|---|
| `01_러프.jpg` | 처음 끄적인 것 | 못 그려도 된다. 과정의 시작 |
| `02_스케치.jpg` | 작업지에 그린 것. **채색 전** | **가장 중요.** 형태를 사람이 정했다는 근거 |
| `03_정리.png` | 선 정리 | |
| `04_채색.png` | AI 채색 | |
| `05_확정도안.png` | 상표 출원에 낼 완성 도안 | 배경 없이 깨끗하게 |
| `작업기록.md` | 언제 · 무엇을 원본과 다르게 정했는지 | |

## 종이 원본은 버리지 않는다

제출은 전부 스캔본으로 하지만, **분쟁이 나면 종이 원본이 가장 강한 증거다.**
연필 농담·지우개 자국·필압은 나중에 지어낼 수 없다.
작업지에 **날짜와 서명**을 직접 쓰고, 클리어파일에 모아 둔다.
