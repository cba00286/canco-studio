## 생성 설정 — 컷마다 같다

| | |
|---|---|
| 모델 | **Nano Banana 2** (image) |
| 비율 | **16:9 가로** |
| 네거티브 | 아래 한 줄을 매번 같이 넣는다 |

```
text, watermark, signature, copyright, blurry, low resolution, deformed, extra limbs, scary, photorealistic human, off-model character, redesigned character, changed face, different proportions, inconsistent character design, different outfit, enlarged horns, oversized horns, elongated horns, long horns, thick horns, prominent horns, adult triceratops horns, growing horns, extra horns, cave, cave interior, enclosed underground space, indoor
```

> **비율은 프롬프트가 아니라 생성 화면의 설정이다.** 프롬프트에 «16:9» 라고 적어도 설정이 1:1 이면 1:1 로 나온다.
