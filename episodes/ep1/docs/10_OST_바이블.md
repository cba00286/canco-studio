# OST 바이블

> 곡 목록의 기계가 읽는 값은 `assets/ost/ost.json`.
> 음원 파일은 `assets/ost/` 에 **아무 이름으로나** 넣으면 된다.

## 왜 곡이 여러 개 필요한가

메인 테마 하나로 오프닝까지 겸하면 두 가지가 망가진다.

**메인 테마는 시리즈의 얼굴**이다. 예고편, 채널 아트, 특별편에서 «이 시리즈다»를 알리는 곡이라
길고 서사가 있어야 한다. **오프닝은 매 화 반복되는 20초짜리 도장**이다. 아이가 40번 듣는다.
짧고, 훅이 하나뿐이고, 따라 부를 수 있어야 한다. 성격이 정반대다.

본편이 4분 36초다. 오프닝이 30초를 넘으면 **본편의 11%**가 매번 같은 곡이 된다.
**20~25초**로 못 박는다.

## 오프닝 — 「쿵! 쿵! 쿵쿵이」

**24초 · 4/4 · 128 BPM · C장조**

### 가사

```
[인트로 — 4초, 발구르기 소리 위에]
쿵! 쿵! 쿵쿵!

[벌스 — 8초]
해가 뜨면 숲이 깨어나
루카 후안 미미 티니 루비
저 멀리서 들려오는 소리
누굴까 누굴까

[훅 — 10초]
쿵! 쿵! 쿵쿵이!
땅이 울리면 친구가 와요
쿵! 쿵! 쿵쿵이!
오늘도 우리 같이 놀아요

[아웃트로 — 2초]
쿵쿵!
```

### 왜 이렇게 썼나

**«쿵쿵»이 여덟 번 나온다.** 아이는 가사를 못 외워도 이 두 글자는 첫 화에서 외운다.
제목이자 능력이자 이름이라, 한 단어가 세 가지를 동시에 각인시킨다.

**다섯 친구 이름을 한 줄에 몰아넣었다.** 6명을 다 부르면 줄이 길어져 못 따라 부른다.
쿵쿵이는 훅에서 따로 부르니 벌스에서는 빠진다. 이 한 줄이 시청자가 캐릭터 이름을
외우는 유일한 통로다.

**«누굴까 누굴까»** — 반복되는 질문으로 훅 직전에 긴장을 만든다. 아이가 대답하고 싶어진다.

**«친구가 와요 / 놀아요»** — 존댓말 종결로 통일했다. 유아 대상 곡에서 반말은 거칠게 들린다.

### 생성 프롬프트 (Suno 등)

```
Upbeat Korean children's TV opening theme, 24 seconds, 128 BPM, key of C major.
Bright ukulele and marimba lead, playful pizzicato strings, light hand claps,
a soft kick drum that lands like a friendly stomp on every "쿵".
Child-like female lead vocal, warm and clear, with a small kids' choir joining
the hook in unison. Cheerful, sunny, adventurous — Saturday morning cartoon energy.
Clean mix, no distortion, nothing scary or dark. Big singable hook.
```

가사는 위 블록을 그대로 붙여넣는다.

### 사양

| 항목 | 값 |
|---|---|
| 길이 | 24초 (±2초) |
| 시작 | 무음 없이 첫 박부터 |
| 끝 | 본편으로 자연스럽게 넘어가게 마지막 0.5초 페이드 |
| 라우드니스 | -14 LUFS (유튜브 기준) |
| 포맷 | WAV로 받아 보관, 편집에는 MP3 320k |

## 캐릭터 모티프

각 캐릭터가 화면을 지배하는 컷에 3~5초짜리 짧은 악기 색을 얹는다.
곡을 따로 만드는 게 아니라 **큐 안에서 악기를 바꾸는 것**이다.

| 캐릭터 | 악기 | 결 |
|---|---|---|
| 쿵쿵이 | 저음 마림바 + 킥 | 둥글고 무겁다. 발이 땅에 닿는 소리 |
| 루카 | 우쿨렐레 스트로크 | 앞으로 밀고 나간다 |
| 후안 | 짧은 글로켄슈필 | 작고 또랑또랑. 말 대신 소리로 존재한다 |
| 미미 | 비브라폰 롱톤 | 느리고 사색적 |
| 티니 | 탬버린 + 빠른 셰이커 | 잠시도 가만있지 않는다 |
| 루비 | 하프 글리산도 | 반짝이고 위로 올라간다 |

## 쿵쿵 파워 사운드

시리즈에서 가장 중요한 소리다. **매번 같아야 한다** — 이 소리가 곧 능력의 정체성이다.

```
1. 앞발이 땅에 닿는 «쿵»  — 저음 킥 + 짧은 서브베이스, 0.1초
2. 뿔로 빛이 차오르는 소리 — 상승하는 신스 스웰, 0.4초
3. 파장이 퍼지는 소리      — 리버스 심벌 + 넓은 리버브, 1.5초
4. 잔향                    — 낮은 종소리가 멀어진다, 2초
```

**무섭게 만들지 않는다.** 폭발음이나 굉음이 아니라 «큰 북» 쪽이다.
쿵쿵이는 파괴하는 게 아니라 울리는 캐릭터다.

## 파일 넣는 법

`assets/ost/` 에 넣는다. **파일 이름은 자유다** — `ost.json` 의 `slug` 나 제목이
이름에 들어 있으면 찾는다.

```
쿵쿵이와 친구들 메인테마.mp3        → main-theme
opening_v3.wav                       → opening
쿵! 쿵! 쿵쿵이 (최종).mp3            → opening
```

## 메인 테마 (확보)

`쿵쿵이와 친구들 메인 테마송.mp3` — **1분 13초**, MP3 VBR 평균 194 kbps · 48 kHz 스테레오.
Suno로 만들었고 앨범아트가 들어 있다(크레용 드로잉 풍, 쿵쿵이·루카·후안·미미).

73초는 예고편과 채널 아트에 딱 맞는 길이다. 그리고 **오프닝을 이 곡에서 파생시킬 수 있는
길이**이기도 하다 — 훅 부분을 24초로 재구성하면 두 곡이 형제처럼 들린다. 완전히 다른 곡을
새로 만드는 것보다 시리즈 정체성에 훨씬 유리하다.

> 배포용으로는 194 kbps로 충분하다. 다만 나중에 리믹스하거나 큐를 파생시킬 계획이라면
> Suno에서 **WAV 원본**을 한 번 받아 `ost/masters/` 에 따로 보관해 두는 편이 좋다.
> MP3에서 다시 자르면 손실이 누적된다.
