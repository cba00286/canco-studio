# 월드 지도 — 쿵쿵이의 세계

> 공식 「확장된 월드맵」을 **두 마을**로 나눈 구조.
> 기계가 읽는 값은 `prompts/characters.json` 의 `world`.

## 두 마을

```
                    ❄ 눈산 · 폭포 ❄
                          │
                       (강의 근원)
                          │
   ┌──────────────────────┼──────────────────────┐
   │      숲속마을         │        해변마을        │
   │   Forest Village     │    Shore Village     │
   │                      │                      │
   │  쿵쿵이  루카         강        후안   티니      │
   │  미미   루비          │      (유빙) (부두)     │
   │                      │                      │
   │  학교 · 박물관         │      등대 · 항구       │
   │  화석센터 · 경기장      │      기차역           │
   └──────────────────────┴──────────────────────┘
        ══════════ 기차 ══════════
```

| | 숲속마을 | 해변마을 |
|---|---|---|
| 사는 친구 | 쿵쿵이 · 루카 · 미미 · 루비 | **후안 · 티니** |
| 지형 | 강, 큰 나무 두 그루, 밭, 바위 지대 | 바다, 부두, 북쪽 유빙 해변 |
| 있는 곳 | 쿵쿵이네 학교(동물 아카데미), 자연사 박물관, 화석 교육 센터, 고대 서식지 디오라마, 원형 경기장 | 등대, 항구와 부두, 기차역, 모래 해변 |

## 왜 이렇게 나누는 게 좋은가

**후안이 해변에 사는 건 설정이 이미 그렇게 되어 있었다.** 차가운 것을 좋아하고, 배로
미끄러지는 게 버릇이고, 집 마당이 눈과 얼음이었다. 해변마을 **북쪽 유빙 구간**에 두면
집을 하나도 안 고치고 그대로 옮겨진다.

**티니도 마찬가지다.** 물웅덩이를 좋아하고 젖으면 반드시 몸을 털어 남에게 뿌린다.
부두 옆 언덕에 두면 그 버릇이 매 화 쓸 수 있는 무대를 얻는다.

**무대가 둘이면 배경이 두 배가 된다.** 40화를 한 마을에서만 찍으면 12화쯤부터 시청자가
«또 거기»라고 느낀다.

## 나뉜 친구들을 무엇이 잇는가

무대를 나누면 «여섯이 매일 어떻게 만나나»가 바로 문제가 된다. 답은 이미 지도에 있다.

**학교** — 쿵쿵이네 학교(동물 아카데미)가 숲속마을에 있다. 여섯이 매일 여기서 만난다.
이게 없으면 두 마을로 나누면 안 된다.

**기차** — 마을 사이를 오간다. 후안과 티니가 이걸로 통학한다.
기차역·기차 안·기다리는 플랫폼이 전부 새로운 무대가 된다.

**강** — 눈산 폭포에서 시작해 숲속마을을 관통하고 해변마을 바다로 나간다.
두 마을이 하나의 물줄기로 이어져 있다. 1화에서 얼음덩어리가 떠내려온 길이기도 하다.

## 이 구조가 만드는 이야기

- **통학** — 아침마다 기차를 타는 둘, 기다리는 넷. 지각·놓친 기차 한 편이 곧 에피소드다
- **초대** — 「우리 마을 놀러 와」. 상대 마을을 처음 보는 회차
- **떨어짐** — 폭우로 기차가 끊긴 날. 여섯이 처음으로 못 만난다
- **바다** — 숲속마을 넷은 바다를 잘 모른다. 후안과 티니가 안내자가 되는 역전

## 1화에 미치는 영향

1화 60컷은 **전부 숲속마을 강가와 개울가**다. 고칠 것이 없다.

후안과 티니가 그날 왜 숲속마을에 있었는지는 설명이 필요 없다 — 폭풍우가 지나간 날 아침
다 같이 모여 놀던 참이었다. 다만 엔딩 EN-03(여섯이 숲길을 따라 집으로 걸어감)은
**둘이 기차역까지 함께 걷는 것**으로 읽으면 자연스럽다. 컷은 그대로 두고 해석만 그렇게 한다.

## 아직 결정이 필요한 것

**유성이 떨어진 「아득히 먼 북쪽 얼음의 땅」이 눈산인가, 훨씬 먼 다른 땅인가?**

| | 눈산이라면 | 훨씬 먼 북쪽이라면 |
|---|---|---|
| 얼음 경로 | 눈산 → 폭포 → 강 → 발견 지점 | 바다나 먼 강을 타고 왔다 |
| 후속 화 | 걸어서 유성 자리에 다시 갈 수 있다 | 큰 원정 — 시즌 후반용으로 아낀다 |
| 1화 첫 나레이션 | 「아득히 먼」을 고쳐야 한다 | 그대로 |
| EN-07 복선 | 산 너머 빛 = 마을에서 보이는 그 산 | 훨씬 먼 곳의 빛 |

눈산이면 **「가까이 있던 비밀」**, 먼 북쪽이면 **「언젠가 가야 할 곳」**이 된다.
