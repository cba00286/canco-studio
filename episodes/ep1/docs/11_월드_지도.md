# 월드 지도 — 자연 마을

> 공식 「쿵쿵이와 친구들의 세상: 확장된 월드맵」 기준.
> **자연 마을 (Nature Village)** 이 시리즈의 무대다.

## 앞선 초안을 정정한다

집 크기 시트의 나열 순서를 지리로 읽어 «한 줄로 늘어선 마을»이라고 적었는데 **틀렸다.**
실제 월드맵은 **원형 마을**이고, 집만 있는 게 아니라 학교·박물관·경기장·기차가 있는
훨씬 큰 세계다.

## 배치

마을은 둥근 땅 위에 있고 **기차 선로가 전체를 한 바퀴 둘러싼다.**
가운데를 강이 흐르고 다리가 여러 개 놓여 있다.

```
        서                    북                     동
   ┌─────────────────────────────────────────────────┐
   │  미미 나뭇잎 집        눈산 · 폭포        루카 나무집  │
   │  (큰 나무 위)      후안 비니 돔          (큰 나무 위)  │
   │                                                 │
   │  쿵쿵이네 학교        티니의 집        자연사 박물관   │
   │  (동물 아카데미)                      화석 교육 센터  │
   │                   루비 당근굴 집                    │
   │                    (강 옆 밭)      쿵쿵이 둥지 바위   │
   │                                                 │
   │  원형 경기장            강 · 다리        해변 · 등대   │

              ═══════ 기차 선로 (마을 순환) ═══════
```

| 구역 | 있는 것 |
|---|---|
| 서 | 미미의 나뭇잎 집 · **쿵쿵이네 학교(동물 아카데미)** · **원형 경기장** |
| 북 | **눈산(Snowy Mountain)** · **폭포** · 후안의 비니 돔 · 티니의 집 |
| 중앙 | 루비의 당근굴 집 · 강과 다리들 · 작은 섬 |
| 동 | 루카의 나무집 · **자연사 박물관** · **화석 교육 센터** · **고대 서식지 디오라마** · 쿵쿵이의 둥지 바위 |
| 남 | **해변과 등대** · **기차 선로**(마을 순환) |

## 이 지도가 열어 주는 것

**쿵쿵이의 집이 자연사 박물관 바로 옆이다.** 쿵쿵이는 공룡이다.
**자기 조상의 뼈가 전시된 곳 옆에서 산다**는 뜻이고, 둥지 바위 안쪽 벽에 화석과
뼈 조형, 손으로 그린 벽화가 있는 것과 정확히 이어진다.
«나는 어디서 왔을까»라는 질문을 한 화 전체로 만들 수 있는 배치다.

**눈산과 폭포가 마을 안에 있다.** 물길의 근원이 여기고, 강이 마을을 관통해 남쪽 바다로 간다.
1화에서 얼음덩어리가 강을 타고 떠내려온 경로가 설명된다.

**학교가 있다.** 여섯이 매일 모이는 무대가 생긴다 — 40화를 끌고 가려면 반드시 필요한 장소다.

**기차와 해변이 있다.** 마을 밖으로 나가는 회차, 물놀이 회차의 무대가 이미 준비돼 있다.

**두 큰 나무가 동서 양끝에 서 있다.** 미미와 루카의 집이다. 마을의 문설주처럼 보이고,
와이드 컷에서 좌우 균형을 잡아 준다.

## 아직 결정이 필요한 것

**유성이 떨어진 «아득히 먼 북쪽 얼음의 땅»이 이 눈산인가, 훨씬 먼 다른 땅인가?**

| | 마을 안 눈산이라면 | 훨씬 먼 북쪽이라면 |
|---|---|---|
| 얼음이 떠내려온 경로 | 눈산 → 폭포 → 강 → 발견 지점. 짧고 명확하다 | 먼 바다나 강을 타고 왔다. 설명이 더 필요하다 |
| 후속 화 | 친구들이 걸어서 유성 자리에 다시 갈 수 있다 | 큰 원정이 필요하다 — 시즌 후반 소재로 아껴 둘 수 있다 |
| 1화 첫 대사 | «아득히 먼»을 고쳐야 한다 | 그대로 쓴다 |
| EN-07 복선 | 산 너머 빛 = 마을에서 보이는 그 산 | 훨씬 먼 곳의 빛 |

**어느 쪽이든 이야기가 되지만 방향이 다르다.** 마을 안이면 «가까이 있던 비밀»,
먼 북쪽이면 «언젠가 가야 할 곳»이 된다.

## 1화 장소를 지도에 앉히면

| 컷 | 장소 | 지도상 위치(추정) |
|---|---|---|
| SC1 | 얼음의 땅 · 크레이터 | 눈산 정상 부근 또는 마을 밖 북쪽 |
| SC2 | 숲속 강가 — 얼음덩어리 발견 | 강 중류, 루비의 밭 근처 |
| SC3 | 강가 공터 — 부화 | 같은 강가 |
| SC4 | 불어난 개울 — 루비 구조 | 강 하류, 다리 근처 |
| EN | 숲길 → 먼 산등성이 | 마을을 가로질러 집으로 |

추정이다. 확정되면 배경 컷의 지형이 서로 이어지고, 2화부터 «어디서 벌어지는 일인지»가
시청자에게 쌓인다.
