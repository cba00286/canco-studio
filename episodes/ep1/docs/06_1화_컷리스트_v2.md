## 제작 방식

| 단계 | 도구 | 비용 |
|---|---|---|
| 키프레임 60장 | OpenArt MCP · Nano Banana 2 Lite | 장당 15크레딧 |
| 영상 60클립 | OpenArt 웹 · **MiniMax H3 (무제한)** | 0 |
| 조립 | FFmpeg | 0 |

MCP로 부르면 Lite도 크레딧이 차감된다(웹 UI에서만 무제한). Pro 24,000크레딧이면
60컷을 2안씩 뽑고 재시도를 3배 잡아도 5,400크레딧 수준이라 여유가 크다.
