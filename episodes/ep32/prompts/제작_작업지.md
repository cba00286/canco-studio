# 32화 얼어붙은 연못에서의 아이스 스케이트 — 제작 작업지

> 쿵쿵이는 무거워서 열두 번 넘어졌다. 「나 안 할래」라고 말한 순간, 여섯이 다 같이 얼음 위에 앉아 버렸다.

`60컷 · 캐릭터 등장 50컷 · 배경만 10컷`

## 만드는 순서

1. **프리비즈** — `previz/블렌더_ep32.py` 를 블렌더에서 실행한다
2. **편집** — 원하는 샷이 나올 때까지 카메라와 배치를 고친다. 여기가 진짜 연출이다
3. **프레임** — 컷마다 첫 프레임(과 끝 프레임)을 PNG 로 뽑는다 — `SC1-01_시작.png`
4. **매핑** — 힉스필드에서 그 컷에 나오는 **캐릭터 마스터 시트**와 **프리비즈 프레임**을 건다
5. **생성** — 컷의 엔진을 고르고 ② 영상 프롬프트를 붙인다
6. 파일명을 컷 ID 로 맞춘다 — `SC1-01.mp4`. 다 모이면 로컬에서 이어붙이기 · 자막 · 소리

> **구도는 프리비즈가 정한다.** 프롬프트로 구도를 다시 말하지 않는다. 두 번 말하면 두 번 움직인다.

> **대사와 효과음은 ② 영상 프롬프트가 만든다.** 나레이션 · BGM · 자막은 로컬에서 얹는다. 이 구분을 헷갈리면 다시 만들어야 한다.

## 생성 설정 — 컷마다 같다

| | |
|---|---|
| 프리비즈 | 블렌더 · 30fps · 1920×1080 |
| 비율 | **16:9 가로** |
| 기본 엔진 | 하이루(미니맥스) |
| 네거티브 | 아래 한 줄을 매번 같이 넣는다 |

```
text, watermark, signature, copyright, blurry, low resolution, deformed, extra limbs, scary, photorealistic human, off-model character, redesigned character, changed face, different proportions, inconsistent character design, different outfit, enlarged horns, oversized horns, elongated horns, long horns, thick horns, prominent horns, adult triceratops horns, growing horns, extra horns, cave, cave interior, enclosed underground space, indoor
```

> **비율은 프롬프트가 아니라 생성 화면의 설정이다.** 프롬프트에 «16:9» 라고 적어도 설정이 1:1 이면 1:1 로 나온다.

> **캐릭터 마스터 시트를 빼먹지 않는다.** 프롬프트에 이름만 적고 시트를 걸지 않으면, 이름은 그냥 글자일 뿐이라 얼굴이 매번 달라진다.

## 엔진을 고르는 법

- 대사가 있는 컷 → **하이루(미니맥스)**. 다른 선택지가 없다 — 한국어 입모양을 맞추는 건 여기뿐이다.
- 대사가 없고 카메라가 움직이는 컷 → **힉스필드 내장**. 카메라 프리셋으로 프리비즈의 움직임을 그대로 준다.
- 대사가 없고 물·불·연기·군중처럼 물리가 무거운 컷 → **클링**.
- 그 외 → 기본값(하이루).
- 엔진을 바꾸면 그 컷만 다시 뽑는다. 앞뒤 컷까지 다시 뽑을 필요는 없다 — 구도는 프리비즈가 잡고 있다.

컷마다 아래에 **엔진**이 이미 적혀 있다. 바꾸고 싶으면 그 컷만 바꾸면 된다 — 구도는 프리비즈가 들고 있으므로 앞뒤 컷은 다시 뽑지 않아도 된다.
